# 2D Game Development - Unity

This repository contains my **2D game development practice projects** created while learning Unity and following YouTube tutorials.

## About

I am using this repository to practice and understand the fundamentals of **2D game development using Unity and C#**.

The project includes experiments and implementations related to player movement, enemies, combat, and other Unity game-development concepts.

## Topics Practiced

- Unity 2D Game Development
- Player Movement
- Enemy Setup
- Enemy Movement & Behavior
- Combat System
- Damage & Health System
- Animations
- Collision Detection
- Rigidbody2D & Physics
- Unity Game Objects and Components

## Project Structure

- `Assets/` — Unity game assets, scripts, scenes, etc.
- `Packages/` — Unity package configuration
- `ProjectSettings/` — Unity project settings
